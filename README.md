# 「未然」—— 校园舆情推演与决策辅助系统

> 全球校园人工智能算法精英大赛（AIC）·「AI+开源」· 方向（一）开源赋能的 AI 应用创新
> 状态：**开发中**

面对校园突发事件，管理者往往在两难中做决定：公开信息会引发舆情，不公开则损耗信任。
**「未然」把这场两难提前演练一遍**——用多智能体仿真重放事件的舆论演化，逐轮追踪
关注、恐慌、信任、极化、风险、稳定六个维度的状态，识别风险拐点，并在你真正开口之前
给出可比较的处置方案。
