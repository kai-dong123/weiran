# 「未然」运行依赖
#
# 分两组：核心运行时 / 仿真内核。
#
# 仿真内核的版本是**刻意锁死的**：上游 MiroFish 的驱动脚本对 oasis 的内部
# 做了 monkey-patch（patch_agent_memory_limit / patch_oasis_environment），
# 这些是私有实现，版本一变就碎。升级前必须重新验证仿真能跑通。
# 详见 docs/开源及第三方资源使用清单.md。

# ---- 核心运行时 ----
# 刻意不引入 openai SDK / python-dotenv：需求各只有十几行，
# 少一个依赖就少一个「评委装不上」的失败点。见 weiran/llm.py、weiran/config.py 的注释。
# Flask **不在这一组**：展示层（weiran/viewer.py）把它当可选依赖，没装时
# `import weiran.viewer` 仍然成功，只有真起服务才报「怎么装」并以非零码退出。
# 核心推演、简报、自检都不需要它 —— 见下方「可选：展示层」。
requests>=2.31
numpy>=1.26

# ---- 仿真内核（版本锁死，勿升级）----
camel-oasis==0.2.5
camel-ai==0.2.78

# camel-ai 自己声明的是 `mcp>=1.3.0`，**上界开放**。pip 会解析到 mcp 2.x，
# 而 mcp 2.x 把 `FastMCP` 从 `mcp.server` 移走了，于是 camel-ai 一导入就炸：
#     ImportError: cannot import name 'FastMCP' from 'mcp.server'
# 这个错误只在「clone 下来装一遍」时出现，开发机上装了旧版就看不到。
# 实测 1.30.0 可用。**这一行不是保险，是必需品。**
mcp<2

# ---- 可选：展示层 ----
# 只有 `python -m weiran.viewer` 需要它。不装也能跑全部推演、简报与自检，
# 也能直接看 data/simulation/ 下的 brief.md 与 gold_check.md（页面与那两份
# 文字读的是同一批数）。
# 不锁死小版本：这一层只用 Flask 最基础的路由与 Response，而 `tests/
# test_viewer.py` 里有一条测试真的把 flask 挡住、验证缺它时的降级路径。
flask>=3.0
